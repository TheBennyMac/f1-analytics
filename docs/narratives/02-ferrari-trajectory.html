Ferrari Championship Trajectory

Does Ferrari consistently squander strong championship positions?

The narrative

“Ferrari always bottles it — they consistently squander strong championship positions as the season progresses.”

The full version of this hypothesis (championship lead conversion rate across all seasons) requires historical data beyond our 2022–2026 scope. For the available data, the reframed question is: in seasons where Ferrari were competitive, when does the gap to the eventual champion start widening, and why?

Method

Cumulative constructor points are tracked round by round. The gap to the championship leader is computed at each round. Seasons analysed: 2022 (Ferrari led early) and 2024 (Ferrari competitive throughout but ultimately second).

import sys
sys.path.insert(0, '../..')

import pandas as pd
import plotly.graph_objects as go
import scripts.export_data as exp

gap_df = exp.read('championship_trajectory')

FERRARI_SEASONS = [2022, 2024]

# Colour encodes constructor; dash encodes season (solid=2022, dot=2024)
CONSTRUCTOR_STYLES = {
    'ferrari':  {'color': '#E8002D', 'name': 'Ferrari',  'width': 3},
    'red_bull': {'color': '#1B3F8B', 'name': 'Red Bull', 'width': 1.5},
    'mclaren':  {'color': '#FF8000', 'name': 'McLaren',  'width': 1.5},
    'mercedes': {'color': '#00D2BE', 'name': 'Mercedes', 'width': 1.5},
}
DASH_BY_SEASON = {2022: 'solid', 2024: 'dot'}

fig = go.Figure()

for cid, style in CONSTRUCTOR_STYLES.items():
    for season in FERRARI_SEASONS:
        data = gap_df[
            (gap_df['constructor_id'] == cid) &
            (gap_df['season'] == season)
        ].sort_values('round')
        if data.empty:
            continue
        fig.add_trace(go.Scatter(
            x=data['round'],
            y=data['gap_to_leader'],
            mode='lines+markers' if cid == 'ferrari' else 'lines',
            name=f"{style['name']} {season}",
            line=dict(
                color=style['color'],
                width=style['width'],
                dash=DASH_BY_SEASON[season],
            ),
            marker=dict(size=5),
            hovertemplate=(
                f"<b>{style['name']} {season}</b><br>"
                'Round %{x}<br>'
                'Gap to leader: %{y} pts<extra></extra>'
            ),
        ))

fig.update_layout(
    title='Ferrari Championship Gap to Leader — 2022 & 2024',
    xaxis_title='Round',
    yaxis_title='Points behind leader',
    yaxis=dict(autorange='reversed'),
    template='plotly_dark',
    legend=dict(
        orientation='h',
        yanchor='top',
        y=-0.15,
        xanchor='center',
        x=0.5,
    ),
    height=540,
    margin=dict(b=120),
)
fig.show()

Ferrari’s cumulative gap to the championship leader by round. Zero = Ferrari are leading; positive = points behind the leader. Solid lines = 2022, dotted lines = 2024.

Findings

Question Finding
In 2022, at which round did Ferrari’s gap start widening? Round 5 — but this followed early Red Bull reliability failures; Ferrari led the championship to that point
In 2024, at which round did Ferrari’s gap start widening? Round 3, then again around Round 7–8; Ferrari recovered from Round 18 onward
How does Ferrari’s decline compare to other competitors? 2022: similar to Mercedes as Red Bull pulled away from the entire field; 2024: Ferrari were second-best for most of the season behind Red Bull, then eventual winners McLaren
Is there a consistent pattern? No — the two seasons show very different trajectories

Partial verdict on two seasons: Not clearly supported. In 2022, the gap widened because Red Bull found dominant pace from mid-season — the same happened to every other constructor. In 2024, Ferrari finished second. See the full historical analysis below.

Historical analysis: championship lead conversion rate (2014–2025)

The deferred question answered: across all seasons from 2014 to 2025, when Ferrari held the constructor championship lead at mid-season, how often did they convert it to a title?

Show code 
import sys
sys.path.insert(0, '../..')
import scripts.export_data as exp
import plotly.graph_objects as go
import pandas as pd

lead_df = exp.read('ferrari_lead_conversion')
Show code 
CONSTRUCTOR_COLOURS = {
    'mercedes': '#00D2BE',
    'ferrari':  '#E8002D',
    'red_bull': '#1B3F8B',
}
DEFAULT_COLOUR = '#888888'

fig = go.Figure()

for cid in lead_df['constructor_id'].unique():
    cdf = lead_df[lead_df['constructor_id'] == cid].sort_values('season')
    name = cdf['constructor_name'].iloc[-1]
    colour = CONSTRUCTOR_COLOURS.get(cid, DEFAULT_COLOUR)

    won = cdf[cdf['won_title'] == True]
    lost = cdf[cdf['won_title'] == False]

    if not won.empty:
        fig.add_trace(go.Scatter(
            x=won['season'], y=[name] * len(won),
            mode='markers',
            name=f'{name} — won title',
            marker=dict(color=colour, size=16, symbol='circle',
                        line=dict(color=colour, width=2)),
            hovertemplate=(
                f'<b>{name}</b><br>'
                'Season: %{x}<br>'
                'Led at mid-season → WON TITLE<extra></extra>'
            ),
            showlegend=True,
        ))

    if not lost.empty:
        fig.add_trace(go.Scatter(
            x=lost['season'], y=[name] * len(lost),
            mode='markers',
            name=f'{name} — lost lead',
            marker=dict(color='rgba(0,0,0,0)', size=16, symbol='circle',
                        line=dict(color=colour, width=2)),
            hovertemplate=(
                f'<b>{name}</b><br>'
                'Season: %{x}<br>'
                'Led at mid-season → lead lost<extra></extra>'
            ),
            showlegend=True,
        ))

fig.update_layout(
    title='Constructor Championship Mid-Season Lead vs Title (2014–2025)',
    xaxis=dict(title='Season', dtick=1, tickangle=-45),
    yaxis_title='Constructor',
    template='plotly_dark',
    height=400,
    margin=dict(b=80, l=120),
)
fig.show()

Who led the constructor championship at mid-season each year (2014–2025), and did they win the title? Filled markers = title won; hollow markers = lead lost.

Full verdict: Supported — across 12 seasons of data.

Ferrari led the constructor championship at mid-season in 3 seasons (2017, 2018, 2022) and converted none to a title — a 0% conversion rate.

Mercedes led in 8 seasons (2014–2021) and converted all 8 — 100%. Red Bull led in 4 seasons (2021–2024) and converted 2 — 50%.

The “bottles it” narrative has a firm factual basis across the Hybrid and Ground Effect eras. The mechanism varies: in 2017 and 2018 Mercedes out-developed them mid-season; in 2022 Red Bull found dominant pace after Round 6. But the outcome — surrendering a mid-season lead — is consistent.
